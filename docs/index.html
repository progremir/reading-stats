How it works

Set it up once, then just read

One afternoon of setup. After that nothing needs a tap, a cable or a sync button.

1

You read

KOReader uploads statistics.sqlite3 whenever WiFi connects and every 30 minutes. The plugin sends each highlight seconds after you make it. Offline changes wait and go out later.

2

Your server keeps it

server.py is a WebDAV folder per account plus the web app and API. Deploy it to Railway by following INSTALL.md.

3

You look

Open the web app in any browser, or install the iPhone app and add the widgets. Everything reads from the same server.

Try it on your computer first

Generate a demo library and sign in as reader. Python 3 is the only requirement.

git clone https://github.com/progremir/readstreak
cd readstreak && scripts/demo_data.py ./demo-data
AUTH_PASSWORD=demo-password-123 DATA_DIR=./demo-data python3 server.py
# open http://localhost:8080

FAQ

Questions before you set it up

Something missing? Open an issue on GitHub.

Which readers does it work with?
Anything that runs KOReader: Kobo, PocketBook, Android readers and jailbroken Kindles. Highlights from the stock Kindle reader come in through My Clippings.txt.
Do I really need my own server?
Yes. That is where your data lives. INSTALL.md walks through deploying it to Railway, and it runs anywhere Python 3 does: a home server, a Raspberry Pi or a small VPS.
What does it cost?
Nothing. Readstreak is MIT licensed. You only pay for whatever hosts your server, if anything.
Is there an app for Android?
Not yet. The web app works in any phone browser and can be added to the home screen. The native app and widgets are iPhone only for now, on TestFlight.
Can my partner and kids use the same server?
Yes. An admin adds each person, who then picks their own password. Everyone sees only their own books, stats and highlights.
What happens when the reader is offline?
Nothing is lost. Stats and highlights wait on the device and go out the next time WiFi connects. Books you send wait on the server in the same way.
What if I lose my Kobo?
Revoke its device password on the account page. The reader never held your account password, so nothing else needs to change.
Can I get my data out?
It is already out. Stats are KOReader's own SQLite file and highlights are plain files in your server's data folder. Highlights also export to Excel from the web app.
